# 隔空写字 · AirWrite

对着摄像头，用食指在空气里写字。手机上也能用。

**在线打开：<https://mmy-ljj.github.io/airwrite/>**

> 浏览器只允许 **HTTPS**（或 localhost）页面使用摄像头，所以请用上面的 https
> 地址，别用局域网 `http://192.168…`。第一次打开要下载约 17 MB 的手部模型，
> 之后浏览器会缓存。

## 手势

| 动作 | 效果 |
| --- | --- |
| 食指伸出 | 笔尖跟着指尖走 |
| 拇指 + 食指捏合 | 落笔（保持捏合继续写，松开提笔） |
| 停顿约 1.1 秒 | 自动分字，开始识别 |
| 快速双击捏合 | 手动分字 |
| 张开手掌（掌心朝摄像头） | 打开 / 关闭画布上的手势面板 |
| 手掌捏合 | 在面板里选择工具（笔 / 橡皮擦 / 缩放） |
| 手背朝摄像头向右横扫 | 字迹结晶成雪花飘散，并清空 |
| 拇指 + 小指 | 撤销 |
| 食指 + 中指 + 无名指 | 清空 |

没摄像头也能玩：页面上的「先看演示」是一段完全合成的动画。

## 本地运行

```bash
python serve.py            # http://localhost:8000/
python serve.py 8123       # 换端口
```

（`file://` 打开会被浏览器拒绝摄像头；`http://localhost` 算安全上下文。）

## 技术说明

- 单页静态站，零构建：原生 ES 模块，`index.html` 用 importmap 指向
  `vendor/lib/vision_bundle.mjs`。
- 手部检测用 MediaPipe Tasks Vision 0.10.14（wasm + `hand_landmarker.task`
  全部离线随仓库交付，断网可用）。
- 手势 → 笔迹 → 字符识别 → 雪花消散，全部在本地浏览器里完成，不上传任何画面。
- 本仓库是部署产物（`dist/airwrite/`）；开发用的测试、脚本不在里面。

## 手机

- iPhone / Android 都可以，Safari 与 Chrome 都测过基本手势。
- 横屏更舒服；把网页「添加到主屏幕」可以全屏打开。
- 手离摄像头 40–80 cm 最稳，光线别太暗。
